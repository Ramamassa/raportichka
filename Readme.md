# Концепция веб-приложения: Электронный журнал и ведомость старосты

## 1. Главная цель проекта

Полная автоматизация рутины старосты:
1. **На парах:** быстро (за 5–10 секунд с телефона) зафиксировать отсутствующих по парам (1 пара = 2 академических часа).
2. **В конце месяца:** получить готовую официальную матричную ведомость пропусков на 31 день без ручного подсчёта часов и переписывания на бумагу.

---

## 2. Ключевая сущность: Структура месячной ведомости

Ведомость строится автоматически в реальном времени на основе ежедневных отметок.

### Формат таблицы ведомости (Матрица пропусков)
* **Строки:** Список студентов по алфавиту (1–28+ человек).
* **Столбцы:**
  * № п/п и ФИО студента (закреплены слева при горизонтальной прокрутке).
  * Колонки с числами месяца: **от 1 до 31** (соответственно количеству дней в выбранном месяце).
  * Итоговая колонка: **«Всего часов за месяц»** ($\sum$ часов за все дни).
* **Ячейка дня:** 
  * Отображает суммарное число пропущенных часов за этот день.
  * Формула: $\text{Количество пропущенных пар} \times 2\text{ часа}$.
  * *Примеры:*
    * Пропустил 3 пары $\rightarrow$ в ячейке стоит **6**
    * Пропустил 2 пары $\rightarrow$ в ячейке стоит **4**
    * Пропустил 1 пару $\rightarrow$ в ячейке стоит **2**
    * Был на всех парах $\rightarrow$ пусто (или точка/ноль в зависимости от стандарта техникума).

### Пример визуализации ведомости:

| № | ФИО студента | 1 | 2 | 3 | 4 | 5 | ... | 30 | 31 | Итого часов |
|---|--------------|---|---|---|---|---|-----|----|----|:-----------:|
| 1 | Иванов И.    | 6 | 4 |   | 2 |   | ... |    |    | **42**      |
| 2 | Кузнецов А.  |   |   | 2 |   |   | ... |    |    | **12**      |
| 3 | Сидоров В.   | 6 | 6 | 6 | 6 |   | ... |    |    | **78**      |

## 3. Сценарии работы в приложении

### Сценарий А: Ежедневная фиксация на парах (Экран «Сегодня»)
1. Открываешь приложение на iPhone (ярлык на рабочем столе).
2. Автоматически выбрана сегодняшняя дата (например, *«1 ноября»*).
3. Сверху переключатель пар: **[ 1 ] [ 2 ] [ 3 ] [ 4 ] [ 5 ] [ 6 ]**.
4. Заходишь на 1-ю пару $\rightarrow$ тапаешь по тем, кого нет (фамилии подсвечиваются красным).
5. Наступает 2-я пара $\rightarrow$ нажимаешь кнопку **«2»**, жмёшь **«Скопировать с 1-й пары»** (список уже заполнен, при необходимости в 1 клик добавляешь/убираешь человека).
6. Данные сохраняются мгновенно. В ведомости за этот день у отсутствующих уже автоматически пересчитались часы:
   * Отметил на одной паре $\rightarrow$ система записала **2 часа**.
   * Отметил на двух парах $\rightarrow$ система обновила на **4 часа**.
   * Отметил на трёх парах $\rightarrow$ система выставила **6 часов**.

### Сценарий Б: Сдача ведомости (Экран «Ведомость»)
1. В конце месяца переходишь во вкладку **«Ведомость»**.
2. Выбираешь месяц (например, *«Ноябрь»*).
3. Видишь готовую таблицу со всеми числами (1–30/31), фамилиями и часами, а также итоговой суммой по каждому студенту.
4. Доступные действия:
   * **«Скачать Excel (.xlsx)»** — таблица скачивается в готовом виде с границами ячеек, точь-в-точь как в бумажном бланке техникума.
   * **«Режим просмотра/печати»** — оптимизированный вид для распечатки или скриншота куратору.

## 4. Архитектура экранов мобильного веб-приложения

### Экран 1: «Отметки» (Быстрый ввод на парах)
* **Календарная плашка:** Сегодняшняя дата (с возможностью клика для перехода на любой день).
* **Селектор пар:** Табы `[Пара 1]` ... `[Пара 6]`.
* **Быстрые действия:**
  * Кнопка *«Скопировать с предыдущей пары»*.
  * Кнопка *«Очистить пару»*.
  * Индикатор: *«Отсутствуют: Х из Y»*.
* **Интерактивный список группы:** Крупные плашки с фамилиями для безошибочного тапа пальцем на ходу. Зеленый = присутствует, Красный = «Н» (отсутствует).

### Экран 2: «Ведомость за месяц» (Матрица 31 день)
* Горизонтальный скролл с фиксированной левой колонкой ФИО (фамилии всегда на виду, дни прокручиваются вправо).
* Подсветка выходных дней (суббота/воскресенье выделены серым фоном, чтобы не путать даты).
* Быстрый клик по ячейке дня: если нужно скорректировать пропуск прямо из ведомости.
* Кнопка **«Экспорт в Excel»**.

### Экран 3: «Настройки группы»
* Поле быстрой вставки списка группы (вставил 25–30 фамилий списком $\rightarrow$ нажал «Сохранить»).
* Автоматическая сортировка по алфавиту.
* Возможность выгрузить резервную копию всех данных.

## 5. Технические особенности под iPhone

* **PWA (Progressive Web App):** Открывается через Safari один раз, нажимается кнопка *«Поделиться» $\rightarrow$ «На экран "Домой"»*. После этого работает в полноэкранном режиме как отдельное приложение.
* **Локальное хранилище (`LocalStorage`):** Все записи живут в памяти браузера телефона. Не требуется сервер, база данных, логины и пароли. Всё работает без интернета.
* **Генерация Excel на лету:** Использование легковесной библиотеки `SheetJS`, которая собирает полноценный файл `.xlsx` прямо на смартфоне.
