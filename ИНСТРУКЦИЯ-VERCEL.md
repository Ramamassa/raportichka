# Пошаговая инструкция: Запуск «Рапортички» на Vercel

Это руководство описывает, как запустить Telegram Mini App «Рапортичка» в облаке на **Vercel** с постоянной базой данных **Upstash Redis** (обе платформы полностью бесплатны для личного использования).

После выполнения этих шагов ваш бот и Mini App будут работать **круглосуточно**, без необходимости держать ноутбук включённым или запускать туннели вроде ngrok.

---

## Что вам понадобится

1. Аккаунт на **[GitHub](https://github.com/)** (бесплатно).
2. Аккаунт на **[Vercel](https://vercel.com/)** (вход через GitHub, тариф Hobby — бесплатно).
3. Токен вашего Telegram-бота от **[@BotFather](https://t.me/BotFather)**.
4. Ваш личный числовой Telegram ID (узнаётся у **[@userinfobot](https://t.me/userinfobot)**).

---

## Шаг 1. Загрузка проекта на GitHub

1. Перейдите на [GitHub.com](https://github.com/) и создайте **новый приватный репозиторий** (New repository), например с именем `raportichka`.
2. В папке `C:\AntiProj\Рапортичка сайт бот` откройте терминал (или Git Bash) и загрузите файлы в созданный репозиторий:

```bash
git init
git add .
git commit -m "Рапортичка Mini App для Vercel"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/raportichka.git
git push -u origin main --force
```
*(Флаг `--force` необходим, чтобы перезаписать начальный пустой коммит/README, который GitHub автоматически создаёт при регистрации нового репозитория)*.

Также в папке есть готовый файл **`Push-To-GitHub.cmd`** — можно просто запустить его для отправки файлов.

---

## Шаг 2. Развёртывание проекта в Vercel

1. Зайдите на [Vercel](https://vercel.com/) под своим аккаунтом.
2. Нажмите **«Add New…»** → **«Project»**.
3. Найдите ваш репозиторий `raportichka` и нажмите **«Import»**.
4. В поле настройки проекта:
   - **Framework Preset**: оставьте *Other*.
   - **Build Command**: `node scripts/build.mjs` (подставится автоматически из `vercel.json`).
   - **Output Directory**: `dist` (подставится автоматически).
5. Нажмите кнопку **«Deploy»**.
6. Через 20–30 секунд проект соберется, и Vercel выдаст вам постоянный домен, например:
   `https://raportichka-xxxx.vercel.app` (скопируйте этот адрес).

---

## Шаг 3. Подключение бесплатной базы данных (Upstash Redis)

Vercel позволяет подключить постоянную облачную базу данных в 1 клик:

1. В панели вашего проекта на Vercel откройте вкладку **«Storage»**.
2. Нажмите **«Create Database»** и выберите **«Redis» (powered by Upstash)**.
3. Примите условия (бесплатный тариф Hobby включает 10 000 операций в день — для одного старосты этого хватит с огромным запасом).
4. Выберите ближайший регион (например, Франкфурт `eu-central-1`) и нажмите **«Create»**.
5. Нажмите **«Connect Project»** и подключите созданную базу к вашему проекту `raportichka`.
   *Vercel сам автоматически пропишет переменные `KV_REST_API_URL` и `KV_REST_API_TOKEN` в проект!*

---

## Шаг 4. Настройка переменных окружения в Vercel

В панели вашего проекта перейдите в **Settings** → **Environment Variables** и добавьте следующие переменные:

| Переменная | Значение | Откуда брать |
|---|---|---|
| `BOT_TOKEN` | `123456789:ABC...` | Токен бота от `@BotFather` |
| `OWNER_ID` | `123456789` | Ваш числовой Telegram ID из `@userinfobot` |
| `WEBHOOK_SECRET` | `любая_случайная_строка` | Любой случайный набор букв/цифр (для защиты webhook) |
| `APP_URL` | `https://ваш-проект.vercel.app` | Адрес вашего проекта, полученный на Шаге 2 |

*(Переменные `KV_REST_API_URL` и `KV_REST_API_TOKEN` уже добавлены на Шаге 3)*.

После добавления переменных перейдите на вкладку **Deployments**, нажмите на три точки `...` у последнего деплоя и выберите **Redeploy** (чтобы сервер подхватил новые переменные).

---

## Шаг 5. Привязка Webhook и кнопки Telegram

Теперь нужно сообщить Telegram, куда отправлять обновления бота.

### Вариант А (через готовый скрипт):
В папке `C:\AntiProj\Рапортичка сайт бот` дважды щёлкните файл **`Setup-Webhook.cmd`** (или выполните команду `npm run setup-webhook`). Скрипт запросит токен, ID и адрес Vercel и настроит всё автоматически.

### Вариант Б (через браузер за 10 секунд):
Откройте в браузере ссылку (подставив ваш токен, адрес Vercel и секрет):
```text
https://api.telegram.org/bot<ВАШ_BOT_TOKEN>/setWebhook?url=https://<ВАШ_ДОМЕН_VERCEL>/api/webhook&secret_token=<ВАШ_WEBHOOK_SECRET>&drop_pending_updates=true
```
В браузере появится ответ:
`{"ok":true,"result":true,"description":"Webhook was set"}`.

---

## Шаг 6. Настройка Mini App в @BotFather

Чтобы кнопка приложения отображалась в профиле бота и в меню:

1. В Telegram откройте **[@BotFather](https://t.me/BotFather)**.
2. Отправьте команду `/mybots`, выберите вашего бота.
3. Перейдите: **Bot Settings** → **Menu Button** → **Configure menu button**.
4. Введите адрес вашего проекта: `https://ваш-проект.vercel.app` и название кнопки: `Рапортичка`.
5. *(По желанию)* Также можете настроить **Configure Mini App** в Bot Settings для кнопки в описании профиля.

---

## Шаг 7. Готово! Проверка работы

1. Откройте своего бота в Telegram.
2. Нажмите кнопку **«Запустить»** или отправьте `/start`.
3. Бот ответит сообщением с кнопкой **«Открыть Рапортичку»**, а в левом нижнем углу появится кнопка меню.
4. Нажмите **«Открыть Рапортичку»**:
   - Приложение откроется прямо в Telegram.
   - Вверху будет статус: **«Сохранено в облаке»**.
   - Перейдите в раздел **«Группа»** → **«Восстановить из файла»** и загрузите вашу резервную JSON-копию (если вы вели отметки ранее).
   - Все отметки сохранятся в базе Upstash Redis.
   - При нажатии **«Скачать Excel»** или **«Скачать копию»** бот отправит сформированный файл прямо в ваш личный чат с ботом!

Теперь ваш ноутбук можно выключить — приложение и бот работают независимо в облаке 24/7!
