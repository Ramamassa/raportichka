# Рапортичка — Telegram Mini App

Отдельная копия существующего сайта. Исходная папка «Рапортичка сайт» не изменяется. Основной запуск: **Start-Bot.cmd**. Требуется Node.js >=24.0.0, Windows, интернет и включённый ноутбук без сна.

## Что бесплатно, а что всё ещё необходимо

Создание бота и Mini App через официальный @BotFather бесплатно. Telegram не является хостингом HTML: нужен публичный HTTPS-адрес. Этот запуск использует бесплатный постоянный домен вашего аккаунта ngrok и его лимиты. Платный домен не требуется. Telegram Bot API использует исходящий long polling — не нужен webhook или настройка роутера. Но веб-интерфейс Mini App загружается через HTTPS-туннель.

## Первый запуск

1. В Telegram найдите официальный **@BotFather**. Отправьте `/newbot`, название «Рапортичка» и свободное имя, заканчивающееся на `bot`. Например, `RaportichkaPersonalBot` — доступность не гарантируется. Сохраните выданный токен, не отправляйте его в чат с инженером.
2. Узнайте свой числовой Telegram ID, например через @userinfobot. Это не username и не номер телефона. Вводится один владелец; остальным доступ закрыт.
3. **Остановите прежний сайт/ngrok, использующий ваш домен.** Две копии на одном домене дадут ERR_NGROK_334. Не запускайте одновременно две копии этого бота: Telegram не разрешает конкурирующий getUpdates.
4. Откройте **Start-Bot.cmd**. Откроется локальная форма. Укажите токен нового бота, свой ID, ngrok Authtoken и домен из https://dashboard.ngrok.com/domains. Существующие секреты старого сайта автоматически не копируются.
5. Нажмите «Сохранить и запустить бота». Дождитесь **БОТ ПОДКЛЮЧЁН**. Откройте нового бота в личном чате, нажмите Start или отправьте `/start`.
6. Нажмите **Открыть Рапортичку**. Владелец также получает кнопку меню «Рапортичка» в чате. Скрипт настраивает её автоматически.

Дополнительно можно включить Main Mini App в BotFather: `/mybots` → ваш бот → Bot Settings → Configure Mini App → Enable Mini App, указав HTTPS-адрес из `.journal-runtime/Telegram-Address.txt`. Это настройка профиля, для кнопки в чате не обязательна. Названия пунктов Telegram могут меняться.

## Каждый день

Двойной щелчок **Start-Bot.cmd**, затем кнопка в Telegram. Не закрывайте консоль, не выключайте интернет и не отправляйте ноутбук в сон. Остановка — Ctrl+C. Повторная настройка: `Start-Bot.cmd --setup`.

## Данные и перенос

- В старом сайте, на телефоне с вашими отметками, откройте «Группа» → «Скачать копию».
- В Mini App откройте «Группа» → «Восстановить из файла», выберите JSON и подтвердите замену. Старое LocalStorage само в Telegram не переносится. Демонстрационный состав не является вашими настоящими данными.
- Серверная основная копия: `.journal-runtime/attendance.json`. Сохранение атомарное, с номером ревизии и проверкой формата. После перезапуска файл читается снова.
- Статус «Сохранено на ноутбуке» появляется после ответа сервера. При обрыве связи остаётся локальный черновик, отображается ошибка и кнопка повторного сохранения. Не закрывайте Mini App до сохранения либо отправки JSON-копии. Локальный черновик также записывается в LocalStorage, но при следующем открытии загружается серверная версия.
- Одновременно редактировать в двух окнах не рекомендуется. При конфликте сервер не затирает чужие новые изменения: сначала сохраните JSON несохранённых данных, затем откройте приложение заново и при необходимости восстановите копию.
- Excel и JSON из Mini App отправляются документами в **ваш личный чат с ботом**. Это сознательная передача файлов Telegram. Восстановление использует системный выбор файла; доступность зависит от клиента Telegram. Печать зависит от WebView; для надёжной печати откройте полученный XLSX на компьютере.
- Регулярно копируйте attendance.json или сохраняйте JSON через интерфейс. Автоматического удалённого резервирования нет.

## Безопасность

Подпись Telegram initData проверяется сервером по HMAC, проверяются ID владельца и срок (24 часа). После истечения откройте Mini App заново. Данные API без авторизации недоступны; локальный режим просмотра не даёт доступа к API. Токен бота никогда не попадает в dist или браузер. Настройки в `.journal-runtime/telegram-settings.json` хранятся локально без шифрования: защищайте учётную запись Windows, не публикуйте эту папку. На Windows флаг mode 0600 не заменяет ACL. При утечке токена отзовите его в BotFather. Вход в аккаунт Telegram означает доступ к приложению: включите двухэтапную аутентификацию.

## Ошибки

- **ERR_NGROK_334:** домен занят старым агентом. Закройте прежнее окно, проверьте https://dashboard.ngrok.com/agents.
- **ERR_NGROK_8012:** старый агент направлен на localhost:80. Новый запуск использует 127.0.0.1 и фактический порт; остановите старый агент и запустите этот файл.
- ngrok может показывать Visit Site и ограничивать трафик на бесплатном тарифе. Mini App не устраняет эти ограничения. Если WebView не пропускает предупреждение, потребуется другой HTTPS-хостинг/туннель; платная услуга автоматически не подключается.
- Нет связи с Telegram: проверьте интернет, токен и отсутствие второй копии. У бота не должно быть активного webhook от другой программы; здесь webhook автоматически не удаляется.
- Сбой хранилища: повреждённый attendance.json не перезаписывается автоматически. Сначала сохраните его копию и восстановите валидную резервную копию на ноутбуке.

## Разработка и проверки

`npm ci` → `npm test` → `npm run build`.
Локальный просмотр: `node scripts/start-bot.mjs --preview`, затем напечатанный URL с `/?preview=1`. Это просмотр интерфейса с демо/локальными данными: бот, API и серверное сохранение выключены. Не используйте как рабочий режим.

Старые scripts/start-journal.mjs и journal-setup.mjs оставлены как общие модули подключения и для исходных регрессионных тестов. Пользователю нужен именно Start-Bot.cmd.
