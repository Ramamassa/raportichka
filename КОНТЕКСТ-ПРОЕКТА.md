# Рапортичка — контекст проекта и передача работы

Дата обновления: Ноябрь 2026 года.

Этот файл объединяет требования пользователя, историю решений, текущее состояние кодовой базы, архитектуру перехода на Vercel и оставшиеся шаги для пользователя. Здесь нет токенов, паролей и содержимого личных отметок.

## 1. Назначение

«Рапортичка» — личное приложение старосты для быстрого учёта отсутствующих по парам и формирования месячной ведомости техникума.

- Работа прежде всего с телефона, включая iPhone (в Telegram Mini App).
- Одна пропущенная пара = 2 академических часа.
- Отметки ведутся отдельно по дате и номеру пары, доступны пары 1–6.
- Итоги дня и месяца рассчитываются автоматически.
- Основные вкладки: **Отметки**, **Ведомость**, **Группа**.
- Название приложения: **Рапортичка**, не «Журнал».

## 3. Выполненный перенос на Vercel

Кодовая база в `C:\AntiProj\Рапортичка сайт бот` полностью адаптирована под serverless-архитектуру Vercel:

1. **Конфигурация Vercel (`vercel.json`)**:
   - `buildCommand`: `node scripts/build.mjs`
   - `outputDirectory`: `dist`
   - Заголовки безопасности (`nosniff`).
2. **Serverless API (`api/`)**:
   - `api/state.js` — загрузка (`GET`) и сохранение (`PUT`) состояния с валидацией HMAC подписи `initData` от Telegram, проверкой владельца `OWNER_ID` и защитой от конфликтов версий (HTTP 409).
   - `api/export.js` — безопасная отправка резервных копий JSON и сформированных табелей Excel (`.xlsx`) непосредственно в личный чат старосты с ботом через `sendDocument`.
   - `api/webhook.js` — serverless-обработчик входящих событий бота от Telegram (команда `/start`, настройка кнопки меню чата). Защищён секретным токеном `WEBHOOK_SECRET`.
   - `api/_storage.js` — атомарный адаптер постоянного хранилища:
     - Облачный режим: **Upstash Redis REST API** (Vercel KV) с атомарным Lua-скриптом (Compare-And-Swap / CAS), исключающим гонки и перезапись чужих изменений.
     - Локальный / тестовый режим: локальный файл или in-memory хранилище без необходимости сетевых подключений.
   - `api/_http.js` — кроссплатформенный хелпер для обработки входящих тел запросов и отдачи ответов.
3. **Автоматизация настройки Webhook**:
   - `scripts/setup-webhook.mjs` и `Setup-Webhook.cmd` — интерактивный инструмент для моментальной регистрации вебхука в Telegram и привязки кнопки меню к домену Vercel.
4. **Интерфейс и PWA**:
   - Сообщения и статусы синхронизации обновлены с «ноутбука» на «облако» (`Сохранено в облаке`, `Сохранение в облако…`).
   - `sw.js` дополнен кэшированием `telegram.js` и явным пропуском `/api/*`, исключающим кэширование сетевых запросов.
   - Минимальная версия Node.js в `package.json` установлена на `>=20.0.0` для полной совместимости со средой исполнения Vercel.

## 4. Согласованный дизайн и экраны

Дизайн полностью сохранён в соответствии с согласованным стилем:
- Цветовая палитра: тёплые пастельные, коричневые и песочные тона.
- Шрифт: **Georgia** для всех элементов.
- Стеклянный плавающий нижний бар навигации (Отметки / Ведомость / Группа) с поддержкой плавного сенсорного перетаскивания и подсветки.
- Экран «Отметки»: быстрый выбор даты и пары (1–6), копирование с предыдущей пары, очистка пары, фильтрация списка группы с сохранением регистра и букв е/ё, счётчик «На паре: N».
- Экран «Ведомость»: автоматический подсчёт пропущенных часов за месяц, таблица с закреплением колонок, выгрузка в красивый печатный Excel.
- Экран «Группа»: управление списком студентов, массовый ввод, автоматическая алфавитная сортировка, скачивание и восстановление резервной копии JSON.

## 5. Переменные окружения для Vercel

В проекте на Vercel (вкладка **Settings** → **Environment Variables**) настраиваются следующие параметры:

| Переменная | Назначение | Пример |
|---|---|---|
| `BOT_TOKEN` | Токен бота от `@BotFather` | `123456789:AA...` |
| `OWNER_ID` | Числовой ID владельца из `@userinfobot` | `123456789` |
| `WEBHOOK_SECRET` | Случайный секретный ключ для вебхука | `a8f3b9c...` |
| `APP_URL` | Публичный адрес проекта на Vercel | `https://raportichka.vercel.app` |
| `KV_REST_API_URL` | URL базы Upstash Redis | Подставляется Vercel автоматически |
| `KV_REST_API_TOKEN` | Токен базы Upstash Redis | Подставляется Vercel автоматически |

## 6. Бесплатные лимиты (Hobby)

- **Vercel Hobby**:
  - Бесплатно для персонального использования.
  - До 100 ГБ исходящего трафика в месяц.
  - Serverless функции: до 100 000 вызовов в день.
  - Время выполнения одной функции: до 10 секунд (достаточно с избытком, сохранение занимает ~30–50 мс).
- **Upstash Redis (Vercel Storage)**:
  - Бесплатный тариф: 10 000 команд в день.
  - Для одного старосты реальная нагрузка составляет 20–50 запросов в день. Лимитов хватает более чем в 200 раз.

## 8. Что осталось сделать пользователю

Подробная пошаговая инструкция написана в файле:
`C:\AntiProj\Рапортичка сайт бот\ИНСТРУКЦИЯ-VERCEL.md`.

Краткий порядок действий:
1. Загрузить папку `Рапортичка сайт бот` в приватный репозиторий на GitHub.
2. В аккаунте Vercel импортировать репозиторий и нажать **Deploy**.
3. На вкладке **Storage** проекта Vercel создать базу **Redis** (Upstash) и привязать к проекту.
4. В **Settings** → **Environment Variables** добавить `BOT_TOKEN`, `OWNER_ID`, `WEBHOOK_SECRET` и `APP_URL`.
5. Запустить `Setup-Webhook.cmd` (или перейти по ссылке `setWebhook` в браузере), чтобы Telegram связался с Vercel.
6. Открыть бота в Telegram, нажать `/start` и пользоваться «Рапортичкой» без включённого ноутбука.
